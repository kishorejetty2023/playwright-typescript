# Playwright TypeScript — Quick Start

A minimal README with only basic installation and execution commands.

## Installation

Install dependencies and Playwright browsers:

```bash
npm install
npx playwright install
```

## Run tests

Run all tests:

```bash
npx playwright test
```

Run using project / environment scripts from package.json:

```bash
npm run test:dev
npm run test:sit
npm run test:uat
```

Run in debug mode:

```bash
npm run test:debug
```

That's it — basic install and execution commands only.
